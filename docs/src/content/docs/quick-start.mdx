## Requirements

Docker or Podman, a persistent volume for `/app/data`, and a browser. `bun` is only needed for local development.

## Run

```bash
docker compose up -d
# open http://localhost:3000
```

The included `docker-compose.yml` builds the `app` target from the repo's `Dockerfile`, runs it on port **3000**, and mounts the database on a named volume. To use a published image instead, set `image: ghcr.io/galene-finance/galene:app-latest` in the compose file.

:::note
The first account on a server is always the **admin**. Optionally load demo data on signup.
:::
