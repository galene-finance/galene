## Budgets

Budgets are per-category limits — week, month, or year — with current-period progress shown on the Budget page, and your spending against the budget line in Trends. On Trends the line is one continuous stroke through each period, thinner than the bars, with a dot where it meets each bar. The chart does not print the budget amount. Hover or tap a dot to see that period's budget. Click a bar to list the transactions in that period, and open the same range on the Transactions page. When a category has spending and no budget yet, Trends can create one at the average spent per period in the current range. Saving it opens the Budget page. Transfer categories are excluded from budgets by default; see [Categories & cashflow](/features/categories-cashflow/).

## Rules

Categorization rules match transactions and apply a category and/or tags. Rules run automatically on new imports from bank sync, and can be applied to existing transactions.

:::note
Budgets and rules are per account — each user sees and edits their own.
:::
